# Simulador educativo de transferências

Aplicação front-end em HTML, CSS e JavaScript puro para praticar um fluxo de transferência com dados fictícios.

## Como executar

Abra `index.html` no navegador. Não é necessário instalar dependências nem iniciar um servidor.

O saldo e o histórico são mantidos apenas durante a sessão da página. Nenhum dinheiro real é movimentado.
